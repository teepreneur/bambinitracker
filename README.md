> **Empowering parents to seamlessly record, track, and understand their child's growth and developmental milestones in real time.**

👉 **[Launch Live Web App](https://bambinitracker.vercel.app)**

---

## 🌟 Key Features

- **Milestone Tracking:** Record physical, cognitive, and social milestones with intuitive date logging.
- **Growth & Health Analytics:** Visual tracking for height, weight, and vaccination schedules.
- **Parent-Centric UX:** Clean, low-friction mobile and desktop dashboard tailored for busy parents.
- **Real-Time Data Persistence:** Instant updates and responsive state management.

---

## 🛠 Tech Stack

- **Frontend:** TypeScript, React, TailwindCSS
- **Deployment:** Vercel

---

## 🚀 Quick Start (Local Setup)

```bash
# Clone the repository
git clone https://github.com/teepreneur/bambinitracker.git

# Navigate to project directory
cd bambinitracker

# Install dependencies
npm install

# Run the development server
npm run dev
```
